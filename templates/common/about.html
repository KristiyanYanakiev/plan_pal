About PlanPal

PlanPal is a collaborative planning web application that allows multiple users to organize activities, share ideas, and make decisions together.

With PlanPal, users can:

  • Create and manage proposals for activities and events
  • Invite other users to participate in proposals
  • Vote on proposals in real time
  • Leave comments and discuss plans with others
  • Track upcoming and past events

Each proposal acts as a shared space where invited participants can collaborate. Only authenticated users can create proposals, vote, and comment, ensuring a secure and personalized experience.

PlanPal is designed to simulate a real-world planning system, where users interact directly with one another rather than through abstract “friend” objects. This makes the application more realistic, scalable, and suitable for real use cases.
